Analysis: Impact of Removing area and rooms Features on Model Performance¶

R-squared Comparison:

Model Configuration Features Included R-squared Change
Original area, rooms, pop_dens, mean_taxable_income, dist_supermarket 0.5247 -
Reduced pop_dens, mean_taxable_income, dist_supermarket 0.0192 -0.5055 (-96.3%)

YES, the R-squared value changed dramatically!

Why Does Removing area and rooms Cause Such a Large Drop in R-squared?

  1. Direct vs. Indirect Predictors:

    • area (apartment size in m²) and rooms (number of rooms) are direct, physical characteristics of the apartment that fundamentally determine its value.
    • pop_dens, mean_taxable_income, and dist_supermarket are contextual, neighborhood-level factors that only indirectly relate to price.
    • In real estate, an apartment's size is the primary driver of price. This is intuitive: larger apartments cost more.

  2. Information Loss:

    • The two removed features capture approximately 96% of the predictive information in the model.
    • Without them, the regression tree must rely solely on demographic and geographic factors, which have much weaker correlation with apartment prices.
    • The model loses the ability to make accurate price predictions.

  3. Feature Importance in Decision Trees:

    • Decision trees select features based on their ability to reduce prediction error (measured by variance reduction).
    • Since area and rooms explain most of the price variation, they are selected early and frequently in tree splits.
    • Removing these features forces the tree to use weaker predictors, resulting in poor performance.

  4. Practical Interpretation:

    • An R² of 0.5247 means the original model explains ~52% of the variance in apartment prices.
    • An R² of 0.0192 means the reduced model explains only ~2% of the variance.
    • This demonstrates that apartment size is the dominant factor in determining price, while location and demographic factors play secondary roles.

Conclusion:

This analysis highlights the critical importance of feature selection in machine learning:

  • Include the most relevant and informative features for the prediction task
  • Domain knowledge is essential: apartment size is obviously important for price prediction
  • A dramatic drop in performance (96% reduction in R²) clearly shows which features carry predictive power

Analysis: Impact of Removing area and rooms Features¶

R-squared Comparison:

  • With area, rooms, pop_dens, mean_taxable_income, dist_supermarket: R² ≈ 0.5247
  • Without area and rooms (only pop_dens, mean_taxable_income, dist_supermarket): R² ≈ 0.0192

The R-squared value has decreased dramatically by approximately 0.5055 (96.3% reduction).

Why Does This Occur?

  1. Feature Importance for Price Prediction:

    • The variables area (apartment size in square meters) and rooms (number of rooms) are the most direct and intuitive predictors of apartment prices.
    • These features capture the primary characteristic that determines real estate value: the size and capacity of the property.
    • Apartment price is fundamentally driven by how much living space and how many rooms it offers.

  2. Weak Predictive Power of Remaining Features:

    • pop_dens (population density): A regional characteristic that may loosely correlate with prices but doesn't directly indicate the property's value.
    • mean_taxable_income: An indicator of the neighborhood's wealth level, useful for explaining price variation across regions, but not as direct as property size.
    • dist_supermarket (distance to nearest supermarket): A convenience factor that has less influence than the property's physical dimensions.

  3. Information Loss:

    • By removing area and rooms, we lose the most informative features that explain apartment prices.
    • The model must now rely on secondary, contextual features (neighborhood characteristics) to predict prices, which are much weaker predictors.
    • This results in poor model performance, evidenced by the R² dropping from 0.52 to 0.02.

  4. Practical Implication:

    • This analysis demonstrates the importance of feature selection in machine learning.
    • Including the most relevant and domain-appropriate features is critical for building accurate predictive models.
    • The dramatic drop in R² clearly shows that apartment size (area) and number of rooms are the dominant factors determining apartment prices, while demographic and location features play a secondary role.

Comparison: max_depth=3 vs max_depth=5¶

Key Differences Observed:

  1. Tree Complexity:

    • With max_depth=3: The tree had 3 levels of splits, resulting in simpler decision paths and fewer leaf nodes.
    • With max_depth=5: The tree has 5 levels of splits, allowing for much more granular partitioning of the data. The visualization shows many more branches and leaf nodes.

  2. R-squared Score:

    • With max_depth=3: R² ≈ 0.4729 (baseline)
    • With max_depth=5: R² ≈ 0.5247 (improved)
    • The increase in R² indicates better fit on the test data, meaning the model explains about 5% more variance in the apartment prices.

  3. Model Interpretability:

    • With max_depth=3: The tree is simpler and easier to interpret - decisions are based on fewer nested conditions.
    • With max_depth=5: The tree is more complex with deeper nesting, making it harder to manually interpret but allowing for more specific price predictions.

  4. Feature Splits:

    • With max_depth=3: Only a few features were selected for splits (e.g., area, pop_dens, rooms).
    • With max_depth=5: More features are utilized throughout the tree (including mean_taxable_income, dist_supermarket), allowing the model to capture more nuanced relationships.

Why These Differences Occur:

The maximum depth parameter directly controls how "deep" the tree can grow. A deeper tree can:

  • Create more specific prediction regions by dividing the feature space into finer partitions
  • Better capture non-linear relationships and interactions between features
  • Achieve better training fit, but risks overfitting to training data noise

However, the improvement in R² suggests that in this case, the deeper tree is capturing genuine patterns in the apartment price data rather than overfitting, as evidenced by the positive improvement on the test set.

Analysis: How Feature Importance Changes When area is Removed¶

YES, the feature importance values change significantly when area is dropped!

Feature Importance Comparison:

Feature With area Without area Change
area 56.75% (removed) -
pop_dens 16.75% 15.36% -1.39%
dist_supermarket 11.61% 27.04% +15.43%
mean_taxable_income 9.15% 17.86% +8.71%
rooms 5.74% 39.74% +34.00%

Why Does Feature Importance Change?

  1. Removal of the Dominant Feature Creates a Vacuum:

    • When area is removed (the most important feature at 56.75%), the model must redistribute its predictive power across the remaining features.
    • The random forest now relies more heavily on the other variables to make predictions, causing their importance scores to increase.
    • This is analogous to removing the strongest team member from a group project—the other members must take on larger roles.

  2. rooms Becomes the New Dominant Feature:

    • rooms increases dramatically from 5.74% to 39.74% (a 5.9x increase).
    • Since rooms and area are correlated (larger apartments tend to have more rooms), rooms now captures the information that area previously provided.
    • Without area, the model must use rooms as a proxy for apartment size.

  3. Other Features Gain Importance:

    • dist_supermarket: Increases from 11.61% to 27.04% (+15.43%). Without direct size information, location factors become more important for price differentiation.
    • mean_taxable_income: Increases from 9.15% to 17.86% (+8.71%). Neighborhood wealth becomes more influential when property characteristics are limited.
    • pop_dens: Relatively stable at 16.75% → 15.36%, suggesting its importance is somewhat independent of area.

  4. Mathematical Reason - Feature Importance Rescaling:

    • In tree-based models, feature importance is calculated as the proportion of variance explained by each feature across all trees.
    • When area is removed, the importance scores are recalculated from scratch with the remaining features.
    • The total importance always sums to 1.0 (100%), so removing a high-importance feature causes all remaining feature importances to be rescaled upward.
    • Without area's 56.75%, the remaining four features now share approximately 100% importance instead of ~43%.

  5. Practical Implications:

    • This demonstrates that feature importance is relative, not absolute—it depends on which features are available.
    • Features can serve as substitutes for each other when better predictors are unavailable (e.g., rooms substitutes for area).
    • The correlation between features matters: When correlated features are removed, other correlated features become more important.

Conclusion:

Feature importance changes when the feature set changes because:

  • Models adapt their predictions based on available information
  • Removing dominant features forces weaker features to play larger roles
  • Importance scores are relative and recalculated whenever the feature set changes
  • This highlights the importance of understanding relationships between features in your dataset
